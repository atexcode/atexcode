### 🕸️ My Current Project:

#### **Employee Time Tracker**

I’m currently developing a comprehensive **Employee Time Tracker** solution tailored for remote teams and small offices. It addresses challenges like lack of proper work monitoring in the absence of supervisors. The project features:

- **Desktop Application** (C#): Tracks employee work time, idle time, keystrokes, active window processes, visited web URLs, and periodic screenshots. Data is stored locally using SQLite3 to handle offline scenarios and synced with the server when online.
- **Web-Based Portal** (PHP Laravel, Vue.js, MySQL): Provides dashboards for employees and admins with features like performance metrics, absence calendars, task assignment, and team management.
- **Status**: Desktop application is in the testing phase, and the web portal is under active development.
